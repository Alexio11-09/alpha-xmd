Quickstart Guide

Setup instructions
  1. Select your country code and enter your WhatsApp phone number on the Overview or Device Pairing page.
  2. Click Generate Pairing Code to request an 8-character authentication key from the server.
  3. On your mobile device, open WhatsApp and go to Settings → Linked Devices → Link a Device.
  4. Tap Link with phone number instead and enter the code shown on your dashboard.
  5. Once connected, open Bot Settings to customize your prefix and automation toggles.

REST API Reference

Backend endpoints
GET /api/stats # Active session count, uptime, and memory usage GET /api/health # Detailed process health and capacity diagnostics GET /api/status?phoneNumber=… # Check connection status for a specific number POST /api/pair # Request a new WhatsApp pairing code POST /api/disconnect # Terminate and purge an active session GET /api/settings?phoneNumber=… # Fetch account configuration (Bearer token required) POST /api/settings # Update account configuration (Bearer token required) GET /api/plugins # List installed command modules POST /api/plugins/toggle # Enable or disable a specific plugin
