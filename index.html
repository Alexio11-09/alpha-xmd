Getting started

Quick guide
  1. Enter your WhatsApp number with the correct country selected.
  2. Generate a pairing code and wait for it to appear.
  3. Open WhatsApp on your phone.
  4. Go to Linked devices → Link a device → Link with phone number instead.
  5. Enter the code shown by Alpha-XMD.
  6. Keep the original browser if you want to manage settings or disconnect later.
